# Agent\-Doc\-Workbench 项目完整开发规划文档

## 一、项目基础概述

### 1\.1 项目名称

Agent\-Doc\-Workbench：面向个人/小团队的Agent活文档协作开源Web工作台

### 1\.2 核心项目定位

开源轻量Web协作工作台，主打**文档作为AI Agent任务唯一协作载体**，区别于传统AI文档工具、企业知识库、Agent编排框架。

核心范式：**Agent 禁止直接改写正式文档**，所有修改统一生成 Diff 变更请求，经人工审核、批注、确认后才可合并生效；原生支持 MCP 协议对接任意外部Agent，不内置大模型推理能力；自带 Token 预算熔断机制，彻底解决个人/小团队多Agent成本失控问题。

迭代核心策略：**v0\.1 MVP 仅实现单Agent能力，多Agent并行能力后置至v0\.2迭代**，严控初期开发复杂度，快速落地可用开源版本。

目标用户：独立开发者、小产品团队、内容创作团队、小型研发团队，**不做重型企业多租户知识库、不面向大型政企组织**。

### 1\.3 核心差异化优势

- **对比 Notion AI / WPS AI**：摒弃AI直接改写文档模式，所有Agent改动可追溯、可审核、可回滚，适配精细化人机协作，杜绝AI无脑改稿、内容不可控问题

- **对比 LangGraph / CrewAI 等编排框架**：不再是纯内存任务输出，提供可视化、可留存、可迭代的文档协作载体，Agent任务过程与结果永久沉淀

- **对比各类AI文档开源项目**：独有「草稿/正式双文档模式」\+「Token预算熔断」\+「MCP通用适配」，精准解决个人小团队成本失控、内容不可控两大核心痛点

## 二、全量业务功能清单

### 2\.1 空间与文档管理系统（基础核心）

#### 2\.1\.1 工作空间能力

- 默认个人私有空间，支持创建多套小团队协作空间（适配2\-10人小团队，无复杂企业组织架构）

- 精细化成员角色权限体系：所有者、编辑者、观察者
       

    - 所有者：全权管理，配置Agent凭证、全局Token预算、成员权限、空间设置

    - 编辑者：编辑文档、发起Agent任务、审批Agent变更请求

    - 观察者：仅只读查看，无任何编辑、审批、操作权限

- 空间全局配置：Agent最大并发上限、全局Token预算阈值、MCP服务统一配置、工具白名单管控

#### 2\.1\.2 文档核心能力

- 树形文件夹管理，支持多级目录、文档分类、自定义标签、文档描述备注

- **核心双文档模式（核心亮点）**

    - 草稿文档：试错专用，Agent可直接自由编辑、无需审批，快速迭代内容、无变更审核流程

    - 正式文档：成果沉淀专用，**所有Agent修改必须生成Diff变更请求**，人工审批通过后方可合并生效，杜绝内容篡改

- 文档基础能力：创建、删除、重命名、移动、归档、回收站恢复

- 文档版本快照：每次合并变更自动生成版本记录，支持一键回滚任意历史版本

- 文档分享：支持生成只读公开分享链接，便捷对外分享成果

### 2\.2 编辑器核心能力

- 基于 ProseMirror \+ Yjs 构建富文本编辑器，底层原生存储 Markdown 格式，双向无缝兼容

- 基础编辑能力：标题、多级列表、表格、代码块、图片、超链接、文本样式调整

- **Diff差异可视化审批（核心功能）**

    - 精准展示Agent变更的新增、删除、修改内容，高亮差异化展示

    - 灵活审批操作：全部接受、部分接受、修改后接受、拒绝变更、添加批注退回Agent重改

    - 每条Diff自动绑定对应Agent身份、关联任务ID、操作时间，全程溯源

- 小团队多人协同编辑（v0\.1简化为非强实时轮询同步，降低开发难度）

- 文档片段批注能力：支持人工对指定段落批注，精准指派Agent针对批注内容迭代修改

### 2\.3 Agent协作能力（核心业务）

#### 2\.3\.1 通用Agent基础体系

- 独立Agent身份体系：每个Agent拥有专属名称、头像、简介、独立MCP凭证，空间内全局可复用

- 精细化权限管控：支持限定Agent仅可操作指定文件夹/指定文档，禁止跨权限访问内容

- 原生MCP客户端：兼容任意外部MCP Server，支持本地/远程Agent接入，无模型绑定限制

- 工具白名单机制：可手动限制Agent可调用的工具，规避越权操作风险

#### 2\.3\.2 Agent任务生命周期管理

- 完整任务实体：任务名称、目标描述、关联文档、执行状态、Token消耗、运行日志

- 任务状态全覆盖：待运行、运行中、已完成、已终止、异常失败

- 人工可控操作：随时手动暂停、终止运行中的Agent任务，杜绝无效消耗

- 双执行模式绑定文档类型

    - 草稿文档：Agent直接编辑执行，无审批流程，快速试错

    - 正式文档：Agent仅生成Diff变更请求，进入审批队列，无直接写入权限

#### 2\.3\.3 版本能力限制规则

- **v0\.1 MVP**：仅支持单Agent串行执行，同一时间仅运行一个Agent任务，无并行多Agent能力

- **v0\.2 迭代**：新增Orchestrator\-Worker多Agent分工模式，按需手动开启（非默认），规避Token成倍消耗问题

### 2\.4 Token成本管控系统（核心差异化、刚需能力）

专为个人/小团队设计，彻底解决多Agent Token消耗失控、账单不可控问题

- **任务级预算管控**：启动Agent任务前，可自定义单任务最大Token上限，到达阈值自动终止任务

- **多维度用量统计**：按空间、文档、任务、单个Agent四大维度，精准统计输入/输出Token、预估消耗成本

- **全局熔断保护**：设置空间总预算，全局额度耗尽自动禁止新Agent任务启动，防止超额消费

- **模型分层适配**：支持为不同Agent分配不同大模型，简单任务调用廉价小模型，复杂推理使用高端模型，极致控本

- **风险提示机制**：开启多Agent高级模式前，强制弹窗提示Token消耗风险，用户确认后才可启动

### 2\.5 变更审批与审计日志系统

- 统一变更审批队列：所有正式文档的Agent修改全部聚合至队列，支持批量审批处理

- 全链路溯源审计日志：记录操作主体（人/Agent）、操作类型、操作时间、关联文档、关联任务ID、变更内容

- 日志不可篡改：保障协作流程可追溯，适配小团队基础合规需求

- 版本迭代：v0\.1仅日志展示，v0\.2新增日志JSON/Markdown导出能力

### 2\.6 导入导出与外部集成能力

- 文档导入导出：支持Markdown单文件导入导出、整文件夹批量导出

- 基础REST API：支持外部程序创建文档、下发Agent任务、读取变更记录、查询用量数据

- 迭代规划：v0\.3对外暴露MCP Server，支持LangGraph、CrewAI等外部Agent框架调用本工作台能力

### 2\.7 辅助配套能力

- AI任务提示词模板库（v0\.2上线）：预置PRD撰写、调研报告、技术方案、内容润色等通用模板，支持自定义保存复用

- 站内消息通知：Agent提交新变更、任务完成/异常实时站内提醒（v0\.1不做邮件、短信通知）

## 三、v0\.1 MVP 明确不做范围（严控复杂度）

为保证快速落地、稳定开源，初代版本坚决砍掉非核心能力，避免项目臃肿、开发延期

- 不做多Agent并行协同能力（延后至v0\.2迭代）

- 不自托管、不自部署大模型推理服务，全程依赖外部MCP/第三方模型

- 不做大型企业多租户、组织架构、部门层级体系

- 不支持Excel、PPT解析渲染，专注文档核心场景

- 无邮件、第三方IM深度集成能力

- 无复杂合规导出、企业级权限风控（适配小团队即可）

## 四、版本迭代里程碑规划

核心目标：跑通完整人机协作闭环，形成可用、稳定的开源基础版本

覆盖能力：空间文档管理、双文档模式、ProseMirror编辑器、单Agent MCP接入、Diff审批流程、Token预算管控、审计日志、基础导入导出、REST API

### 4\.2 v0\.2 功能增强版本

核心目标：提升协作效率、拓展场景、优化成本控制

新增能力：按需开启多Agent分工协作、docx文档导入导出、提示词模板库、审计日志导出、审批批量操作优化

### 4\.3 v0\.3 生态扩展版本

核心目标：打通外部生态、提升性能、拓展场景边界

## 五、核心业务完整闭环（v0\.1可演示）

1. 用户创建个人/团队空间，新建**正式文档**，手动录入基础内容与框架

2. 配置外部MCP Agent连接，设置单任务Token预算阈值，下发文档优化/撰写/整理任务

3. Agent通过MCP协议按需读取文档片段（不加载全文，控Token），生成内容修改

4. Agent提交Diff变更请求，进入审批队列，页面可视化展示增删改差异

5. 人工精细化审批：部分接受、修改后确认、拒绝无效变更、批注退回重改

6. 审批通过后，变更合并至正式文档，自动生成版本快照，同步记录Token消耗与审计日志

7. 试错迭代场景：复制文档至草稿区，允许Agent自由编辑调试，无需审批，降低协作成本

8. 任务完成后，可导出Markdown成果、查看完整用量统计，随时终止闲置任务避免消耗
